## How to Run

**1. Download**
Download the build for your system:

| System | File |
| :-- | :-- |
| Windows | [RemoteX-Setup.exe](https://github.com/X5Coder/remotex/releases/latest/download/RemoteX-Setup.exe) |
| macOS | [RemoteX.dmg](https://github.com/X5Coder/remotex/releases/latest/download/RemoteX.dmg) |
| Linux | [RemoteX.AppImage](https://github.com/X5Coder/remotex/releases/latest/download/RemoteX.AppImage) |

All versions are in [Releases](https://github.com/X5Coder/remotex/releases).

**2. Open the app**
Open RemoteX normally on the computer you want to control.
If it asks for administrator permission, allow it.

**3. Read your credentials**
The app window shows your **Device ID** and **Password**.

**4. Open the web client**
Go to [x5coder.github.io/remotex](https://x5coder.github.io/remotex/) from any device.

**5. Connect**
Enter the **Device ID** and the **Password**, and the control opens.

> The builds are unsigned, so the first time:
> - **Windows:** click *More info → Run anyway*
> - **macOS:** right-click the app → **Open**
> - **Linux:** run `chmod +x RemoteX.AppImage`
